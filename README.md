- **RAG Systems** — LangChain + FAISS + Neo4j Vector, deployed on GCP Cloud Run. Turning 3-4 hours of manual document analysis into 2-minute AI-powered answers.
- **Multi-Agent Pipelines** — Generator-Validator architectures, Plan-Execute frameworks, Think-Act-Observe loops. Agents that are reliable, not just impressive.
- **LLM Fine-Tuning** — SFT models for code translation and domain reasoning. Taxonomy-aligned training datasets for classification, generation, and reasoning tasks.

- **Computer Vision** — YOLOv8/v5 object detection, OCR pipelines (Tesseract), NER systems achieving 95% OCR accuracy and 90% NER precision.
